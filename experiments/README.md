# Experiments

Planned experiment sequence:

1. A/A false-positive calibration.
2. Controlled slowdown injection.
3. Detection power versus sample count.
4. Method comparison under matched assumptions.
5. Noise stress testing.
6. Public historical benchmark case study.

Use synthetic data first. Keep random seeds and experiment configurations fixed for reproducibility. Do not label simulated or hardware observations as ground truth unless the label is justified.
